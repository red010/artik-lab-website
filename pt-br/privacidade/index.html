Aviso sobre o tratamento de dados

Quem trata os dados dos formulários, o que se recebe, para que servem, por quanto tempo e o que pode pedir quem escreve.

Atualizado em 7 de setembro de 2026.

Quem trata os dados

Quem trata os dados

Os dados dos formulários são tratados pela Artik Lab s.r.l., controladora dos dados, com sede em Via Principe Amedeo 11, Turim, Itália, IVA IT04120810041, e-mail dtr@ar-tik.com.

O que se recolhe

O que se recolhe

Através dos formulários do site recebem-se o endereço de e-mail e o texto em que se indica o trabalho ou a decisão a enfrentar. Não se usam cookies de perfilamento nem ferramentas de análise de terceiros nestas páginas.

Para que servem os dados

Para que servem os dados

Os dados servem apenas para responder ao pedido e para gerir o eventual seguimento da conversa.

Por que os dados podem ser usados

Por que os dados podem ser usados

Os dados são usados porque a pessoa escreveu para pedir um contacto ou para preparar um eventual trabalho (medidas pré-contratuais, art. 6 GDPR).

Por quanto tempo as mensagens ficam guardadas

Por quanto tempo as mensagens ficam guardadas

As mensagens ficam guardadas pelo tempo necessário para tratar o pedido.

O que se pode pedir sobre os próprios dados

O que se pode pedir sobre os próprios dados

Pode-se pedir para consultar, corrigir ou apagar os dados, ou para limitar o seu uso, escrevendo para dtr@ar-tik.com.

Quem recebe as mensagens

Quem recebe as mensagens

As mensagens chegam a pessoas da Artik Lab. Não são cedidas a listas comerciais.
